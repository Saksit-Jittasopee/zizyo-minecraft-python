# Project files for https://youtube.com/zizyo

## Keybinds

<ul>

<li> 1 - Place Grass Block </li>

<li> 2 - Place Sand Block </li>

<li> 3 - Place Dirt Block </li>

<li> 4 - Place Planks Block </li>

<li> 5 - Place Stone Block </li>

<li> 6 - Place Cobblestone Block </li>

<li> 7 - Place Brick Block </li>

<li> 8 - Place Netherrack Block </li>

<li> 9 - Place Bedrock Block </li>

<li> Left Click - Break Block </li>

<li> Right Click - Zoom In </li>

<li> WASD - Control Movement </li>

<li> Space Bar - Jump </li>

<li> Ctrl + Shift + Alt + Q to close ursina window </li>

</ul>
